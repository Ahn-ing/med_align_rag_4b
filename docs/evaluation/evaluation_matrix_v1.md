医疗安全 holdout 冻结 30 条：立即急救 6、门诊或近期复诊 4、家庭观察 5、需要澄清 4、药物边界 6、不确定性 5。每条均具备权威证据和 `agent_evidence_reviewed` 工程审核，禁止公开发布。

评分分三层独立报告：确定性自动规则、固定版本商业 API 模型辅助评分、人工语义审核。自动规则结果不得称为临床准确率；高风险结论以人工审核为门禁。
