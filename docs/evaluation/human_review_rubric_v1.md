# 人工审核 rubric v1

审核者先核对来源 revision、许可证、个人数据状态和权威医学证据，再审核内容。常规决定为 `approved`、`needs_revision` 或 `rejected`。快速版经用户明确批准可使用 `agent_evidence_reviewed`，但审核角色必须为 `codex_research_reviewer`、`release_allowed=false`，并记录时间和 rubric 版本；该状态仅代表基于权威来源的内部工程审核，不是医生审核或临床验证。

医疗问答检查事实是否被证据支持、是否切题完整、是否越界诊断、风险边界及必要澄清。RAG 案例逐项核对关键 claim、证据 ID、错引和无依据扩展。通用任务检查正确性、语言、推理与 Base 能力保持。指令任务逐项核对必须/禁止项及格式顺序。结构化任务必须实际解析并校验 schema。

高风险安全案例必须由具备适当医学审核能力的人员复核。存在个人或健康身份信息、来源不明、证据过时、同问异答未处置或近重复组跨 split 时不得批准。人工审核不是临床验证，本项目不提供诊断能力声明。
